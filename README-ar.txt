طريقة بناء الـ APK (مرة واحدة فقط)

الطريقة 1 - Android Studio:
  1) افتح Android Studio ثم File > Open واختر مجلد MudeerCards.
  2) انتظر انتهاء Sync ثم Build > Build APK(s).
  3) الملف: app/build/outputs/apk/debug/app-debug.apk

الطريقة 2 - بدون كمبيوتر قوي (GitHub Actions):
  ارفع محتوى هذا المجلد إلى مستودع GitHub خاص، ثم Actions > Build APK > Run workflow،
  ونزّل الملف kuroot-apk من نتيجة التشغيل.

التطبيق بعد التثبيت: بلا إذن إنترنت إطلاقاً وبلا أي روابط.
ملف الواجهة: app/src/main/assets/index.html
